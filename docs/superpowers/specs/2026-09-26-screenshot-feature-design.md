# ShadowPTY Screenshot Feature Design

## Overview
This feature introduces a `tui_take_screenshot` MCP tool that allows users to capture the current state of a terminal session as an SVG image. It uses the `termsnap-lib` crate to emulate terminal state and generate the SVG.

## Architecture

To avoid breaking the semantic output generated by `vt100` in the existing `tui_read` tool, `termsnap_lib::Term` will be run side-by-side with the existing `vt100::Parser`. Both parsers will independently maintain their own screen grid representations by consuming the same stream of bytes coming from the PTY.

### State Management (`pty_manager.rs`)
The `TuiSession` struct will be updated to hold a mutex-guarded `termsnap_lib::Term` instance:

```rust
pub struct TuiSession {
    // Existing fields...
    pub parser: Arc<std::sync::Mutex<vt100::Parser>>,
    pub snap_term: Arc<std::sync::Mutex<termsnap_lib::Term<termsnap_lib::VoidPtyWriter>>>,
}
```

The terminal is initialized with a `VoidPtyWriter` because ShadowPTY does not currently respond to ANSI device status requests automatically, so throwing away `termsnap-lib`'s ANSI responses is acceptable.

### Stream Processing (`pty_manager.rs`)
In the `run_pty_reader` thread, the incoming data chunks from the terminal will be duplicated to both parsers. Since `termsnap_lib::Term` processes byte-by-byte, it will iterate through the chunk:

```rust
if let Ok(mut locked_parser) = parser.lock() {
    locked_parser.process(chunk);
}
if let Ok(mut locked_snap) = snap_term.lock() {
    for &byte in chunk {
        locked_snap.process(byte);
    }
}
```

The `resize` method on `PtyManager` will also be updated to ensure `snap_term.resize(rows, cols)` is called alongside `parser`.

### Tool Implementation (`server.rs`)
A new tool, `tui_take_screenshot`, will be added to `ShadowPtyServer`. It acquires the `snap_term` lock, extracts the current screen state, and formats it as an SVG string using a set of default monospace fonts.

```rust
#[tool(
    name = "tui_take_screenshot",
    description = "Generates an SVG screenshot of the current terminal screen."
)]
pub async fn tui_take_screenshot(&self) -> Result<CallToolResult, rmcp::ErrorData> {
    // Implementation:
    // 1. Retrieve the snap_term from the active session.
    // 2. Call locked_snap.current_screen()
    // 3. Render SVG using screen.to_svg() with fallback monospace fonts.
    // 4. Return as text block in CallToolResult.
}
```

## Dependencies
- `termsnap-lib = "0.4.0"` will be added to `Cargo.toml`.

## Git Worktree / Branch Strategy
- The work will be done on a dedicated feature branch as requested by the user, isolating the addition of dependencies and refactoring of core PTY logic from the main development branch.
